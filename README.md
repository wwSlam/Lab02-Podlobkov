1. double хранит число в двоичном коде, простые дроби не могут быть представлены в двоичной системе ,а у decimal таких проблем нет.
2. вы увидите 0. Это называется переполнение (overflow): если результат не помещается в
границы типа, значение "оборачивается" по кругу заново от минимума.
3. var — это не аналог динамической типизации Python. Тип всё равно
определяется один раз, во время компиляции, просто вы не пишете его руками —
компилятор смотрит на то, что справа от =, и подставляет тип сам. После объявления
var age = 20; переменная age — это самый обычный int, и присвоить ей потом строку
так же нельзя, как обычной int-переменной.
4. Console.ReadLine() всегда возвращает string, даже если пользователь ввёл число.
Если нужно число — строку придётся преобразовать.
5. int.Parse при ошибке выбрасывает FormatException и программа завершается с ошибкой, а int.TryParse возвращает False.
6. False in int.TryParse сообщает, что преобразование строки в число закончилось неудачей. В переменную переданной через out, записывается значение по умолчанию - 0.
7.Пример TryParse считывает возраста или кол-во товаров,вводимых пользователем через консоль или форму интерфейса.  TryParse защищает приложение от аварийного завершения и позволяет попросить повторный ввод.
